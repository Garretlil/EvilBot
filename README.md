# Злой инвестор

Русскоязычный веб-тренажёр защиты стартапа. Один бизнес-ангел задаёт пять адаптивных вопросов, оценивает десять критериев «Стартап как диплом» и даёт три действия до выступления.

## Развёрнуто

- Приложение: `/home/user1/evil-investor`
- Сервис: `evil-investor.service`, автозапуск systemd, пользователь `user1`
- Python 3.12, только стандартная библиотека; nginx — обратный прокси
- Backend слушает только `127.0.0.1:8080`; nginx принимает HTTP на порту 80
- ИИ: DeepSeek; модель и адрес API задаются окружением
- Секрет: `.env`, права 600; не включать в Git/архивы
- База: `data/sessions.sqlite`, права 600; не включать в Git/архивы

## Локальный запуск

Нужен Python 3.12+. Зависимости pip отсутствуют.

```bash
mkdir -p data
cp .env.example .env
chmod 600 .env
# Заполнить DEEPSEEK_API_KEY в .env
python3 server.py
```

Открыть `http://127.0.0.1:8080`. Для внешнего доступа использовать nginx перед приложением. Для публичного использования подключить HTTPS на собственном домене; текущая конфигурация — HTTP по IP.

```bash
sudo systemctl status evil-investor
sudo systemctl restart evil-investor
sudo journalctl -u evil-investor -n 50 --no-pager
sudo nginx -t
```

## Состояния и оценка

Сервер хранит счётчик вопросов. Модель генерирует только следующий вопрос или структурированный отчёт. Ответ сохраняется до обращения к модели; при ошибке повтор того же ответа продолжает тот же ход. Шестой вопрос невозможен на уровне переходов сервера. Двойная отправка завершённого шага возвращает текущий результат.

10 критериев с равными весами: проблема, бизнес-модель, рынок и конкуренты, финмодель, ИС/регистрация, продажи, риски, горизонт, уникальность, инвестиционная привлекательность. Якоря 0–4 закреплены в `CRITERIA` внутри server.py. Не обсуждавшийся критерий получает null/НД. Известное отсутствие продаж — 0. Итог: сумма известных баллов / 40 × 100; НД не добавляет баллов. Показывается охват; менее 7 известных критериев — предварительная оценка. Оценивается представленность данных, а не объективная вероятность успеха бизнеса.

Для числового балла обязательна дословная цитата из питча/ответов; сервер проверяет наличие цитаты. Это подтверждает источник суждения, но не доказывает достоверность заявления пользователя. Внешнего поиска нет. В рекомендациях проверяются ровно три элемента, известные критерии и суммарный бюджет времени.

## Приватность и ограничения

- Питч/ответы передаются DeepSeek. Его хранение регулируется условиями провайдера.
- Серверные сессии автоматически удаляются в течение 24 часов с момента создания с очисткой за 5 минут до срока; чтение сессий после 24 часов запрещено сразу. IP и обезличенные идентификаторы лимитов хранятся до 24 часов с тем же интервалом очистки.
- Текст питчей/ответов не журналируется приложением по умолчанию. Логи содержат пути API, статусы и время операций.
- Браузер сохраняет черновик, незавершённый ответ и до десяти завершённых раундов. Кнопка удаления очищает данные в браузере и связанные серверные сессии; лимиты запросов сохраняются до истечения окна для защиты от обхода.
- Сессии доступны только с непредсказуемым HttpOnly SameSite cookie; при HTTPS он также Secure.
- Нет HTML-рендеринга пользовательского ввода, внешних инструментов, выполнения кода и обхода по URL из питча. CSP запрещает внешние скрипты.
- До 5 новых раундов в час на браузер, 15 на IP, 80 суммарно в сутки. Это начальные настройки защиты API-бюджета; общий Wi-Fi может потребовать пересмотра IP-лимита.
- При ошибке схемы выполняется одна повторная генерация. У провайдера тайм-аут 42 секунды на запрос. Финальный отчёт может потребовать двух генераций.
- Максимум 4 параллельных вызова модели. Сайт рассчитан на прототип и небольшую демонстрацию.

Тестовые сессии удаляются в конце. Содержательность и тон дополнительно проверяются вручную. Предоставленный датасет из 15 заявок включён в tests/fixtures; реальный прогон описан ниже.

## Что требуется для конкурсной сдачи

Подтвердить инвестора после жеребьёвки, открыть HTTP/HTTPS в сетевых правилах облака, подключить домен/HTTPS, опубликовать исходники без секретов в открытом репозитории и подготовить one-pager. Текущий README описывает реально реализованный прототип. Для месячных метрик таблица events хранит обезличенный идентификатор браузера, проекта, время, версию и оценки без текста беседы не более 30 дней. Расчёт: metrics.py. Голосовой режим не реализован. Сравнение раундов работает для повторных раундов одного проекта, в одном браузере, с одинаковой версией рубрики.

## Настройки окружения

Ключ, модель, адрес API, адрес/порт приложения, тайм-аут, параллельность, лимиты и сроки хранения задаются в `.env`. `.env.example` содержит пустой ключ и безопасные значения по умолчанию. Изменения применяются после `sudo systemctl restart evil-investor`. Если меняется APP_PORT, нужно согласованно изменить upstream nginx. `.gitignore` исключает `.env` и его варианты, ключи, базы сессий, логи, локальные окружения; `.env.example` остаётся доступным для репозитория.

## Датасет и источники оценки

В комплект включён предоставленный датасет из 15 заявок и `check_dataset.py`. Содержимое датасета используется только тестовым кодом, не служит набором заготовленных ответов приложения. Полный прогон запускается командой `python3 check_dataset.py --phase full` на автоматически изолированной копии сервера; подробности — `tests/README.md`.

Для вопросов и отчёта сервер строит каталог коротких дословных фрагментов исходного питча и ответов. Модель выбирает идентификаторы; сервер подставляет исходные цитаты и проверяет их наличие. Старый формат дословной цитаты поддерживается для совместимости. Такой механизм не доказывает истинность заявлений пользователя, но исключает изменение текста выбранного фрагмента моделью. Ошибка схемы получает безопасный код для повторной генерации; текст питча/ответов в технический журнал не выводится.

Проверка предоставленного датасета 6 ноября 2026 года: 15/15 сценариев (13 полных раундов и 2 обоснованных отказа). После ручного просмотра отдельно повторены 08, 12 и 15; 3/3 успешно. Изолированные проверки: 59/59. Полные отчёты выдаются отдельно от исходников; код тренажёра не содержит списка проектов или заготовленных ответов под датасет.
